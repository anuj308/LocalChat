## Getting Started

First, install ollama https://ollama.com/download to run LLm in your pc

then install a model like here i am using deepseek one
```bash
ollama run deepseek-r1:1.5b
```

then run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can also use different model by editing the model name. but it should be correct and installed in the pc
